④ 手機版使用與備份

手機與電腦不會自動同步資料。請先在電腦主程式匯出最新的「完整私人備份」，確認裡面已包含新加入的文件，透過 AirDrop、USB 或可信賴的加密方式將 JSON 傳到手機；不要上傳公開 GitHub。

iPhone：Safari 網頁與已加入主畫面的 PWA 可能使用不同的本機資料。先決定要在何處使用，不要移除既有 PWA；在相同環境的主程式匯入備份後，才能在該環境查看私人文件。若本頁顯示「尚未載入私人旅程」，不要因為電腦有資料就認為手機已同步。

Android：使用同一個 Chrome 使用者設定檔開啟主程式並匯入備份，接著開啟此文件頁確認。若是其他瀏覽器或另一個 PWA 資料環境，仍須分別確認。

匯入前：手機若已記帳或寫日記，先備份手機本機資料，原則上選主程式的「合併（1）」；只有確認該環境沒有要保留的私人資料，才考慮「完整還原（2）」。完成後在有網路時開啟首頁和本文件頁，最後用飛航模式測試離線觀看。

提醒：本頁僅能讀取目前瀏覽器／已安裝 PWA 的儲存空間。若你在 iPhone Safari 打開的本頁與主畫面 PWA 不同環境，無法直接看到主畫面 PWA 的資料。請勿用清除資料或重新安裝方式排除。
