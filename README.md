# Japan Road Trip V2.11.2 — 官方路況與雙人付款人記帳更新版

**此資料夾僅含可公開的 PWA 程式、通用文化導讀、無真實日期的示範行程以及公開信用卡規則。**

## 本次更新

- 17 章原始景點文化導讀全文回補，清除原始私人行程日期、交通預約及個人語句；行程卡的 `trip-guide.html#...` 對應章節可使用。
- 20 項導讀入口（17 章文化導讀 + 3 則既有通用導讀）在原本「景點導讀」頁能閱讀，行程卡保持原有「完整導讀」按鈕。
- 刷卡頁新增店家及付款方式，根據私人匯入的持卡、登錄及額度資料將保守估算與待確認加碼分開。**公開檔案沒有使用者持卡名單、登錄狀態。**
- 住宿卡相片從私人 JSON 中的 `hotels[].image` 讀取。公開檔案沒有東京京橋飯店照片或真實入住資料。
- Service Worker 新快取只快取通用靜態檔案，不會快取 JSON 匯入檔。

## 部署／更新

GitHub Pages：只把本 ZIP 解壓縮後的**公開檔案**上傳至 `angechun/japan-road-trip-2026-pages` 的 `main` 根目錄。更新後原本網站 URL 不變，不需重新建立 Repository。備份原網站版本與私人 JSON 後再更新。

**私人檔案 `JapanTrip-V2111-PRIVATE-COMPLETE-2026-11-05.json` 不能上傳這個 Repository**。私人資料只由本人手動選檔匯入，各裝置 IndexedDB 互不同步且未加密。

## 現行限制

- 信用卡回饋與資格是依使用者提供的彙整資料及銀行官網部分條款建立的候選估算，**非銀行保證回饋**；加碼登錄、商店請款名稱、共用上限及國外交易費須另查當期條款。
- 不含私人 Suzuki QR 票券。離線使用、iOS 裝置完整體驗及舊版資料遷移尚需實際裝置驗收。
- 之前 V2.11.0 私人 JSON 格式仍可使用；相同 ID 合併不會覆蓋，若要讓私人新資料生效，先備份再選擇完整還原。

## V2.11.2 新增功能
- 行程「實用連結」及標籤，私人行程可連至山梨縣官方道路管制頁。
- 新增柴犬／貓咪／未指定付款人，支援新增、編輯（不刪原收據）、必買品轉記帳、付款人統計、篩選及 CSV。
- 舊支出沒有 payer 欄位時一律顯示未指定，不推斷是誰付錢。
- 舊 IndexedDB 及私人 JSON 格式相容，不清除任何私人資料。
